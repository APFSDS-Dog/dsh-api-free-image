# API免费生图

给 **DeepSeek Harness（DSH）** 装上的免费 AI 画图插件。不用写代码，装好、填个 Key，直接在对话里说「画一只戴墨镜的柴犬」就行。

---

## 三步开始用

### 第 1 步 · 拿一个 API Key（免费）

1. 打开 **[硅基流动注册页](https://cloud.siliconflow.cn/i/Qt3zAfmr)**（邀请码 `Qt3zAfmr` 已内置，直接注册即可）
2. 手机号注册并登录
3. 进入「API 密钥」页面 → **新建密钥** → 复制那串 `sk-` 开头的内容

> 💡 用的是免费的 Kolors 模型，出图不花钱。但平台要求账户余额 **≥ 0**，建议充 **1 元**当保证金，否则会提示「余额不足」。

### 第 2 步 · 安装插件

**方式 A · 命令行**（推荐）

```bash
dsh plugin --profile desktop add dsh-api-free-image
```

**方式 B · 图形界面**

DSH → 左下角 **设置** → **插件** → **添加** → 填入包名 `dsh-api-free-image` → 确定。

**方式 C · 用 `.tgz` 文件**

别人送了你一个 `dsh-api-free-image-1.1.0.tgz`：DSH → 设置 → 插件 → 添加 → 选中这个文件即可。

### 第 3 步 · 填入 Key，开始画图

1. 打开 **设置 → 插件 → API免费生图**
2. 把 `sk-` 开头的那串 Key 粘进输入框 → 点 **保存**
3. 回到对话，直接说人话就行：

   > 画一只戴墨镜的柴犬，扁平插画风
   >
   > 来张 16:9 的赛博朋克城市夜景

## 图片存在哪里？

- **默认位置**：系统的「图片」文件夹（Windows 是 `C:\Users\你的用户名\Pictures`），**按日期分文件夹**存放。
- **想换位置**：设置卡片里点 **「更改保存位置」**，选一个新文件夹即可；点 **「恢复默认」** 可以改回来。

## 常见问题

**提示「本分钟已经出过 2 张」？**
免费模型有限速，每分钟最多 2 张、每天最多 400 张。等一分钟再画就行。

**提示「余额不足」（402）？**
去硅基流动后台充 1 元。免费模型也要求账户余额 ≥ 0。

**提示「API Key 无效」（401）？**
Key 复制错了或已被删除，回第 1 步重新建一个。

**卡片显示「未配置」，但我明明填过 Key？**
Key 只存在本机。重装系统、换电脑后需要重新填一次。
