# API免费生图

给 **DeepSeek Harness（DSH）** 装上的免费 AI 画图插件。不用写代码，装好、填个 Key，直接在对话里说「画一只戴墨镜的柴犬」就行。

---

## 三步开始用

### 第 1 步 · 拿一个 API Key（免费）

Key 就是一把「钥匙」，插件拿着它去硅基流动那里帮你画图。整个过程大概 3 分钟：

1. **打开注册页**：**[cloud.siliconflow.cn/i/Qt3zAfmr](https://cloud.siliconflow.cn/i/Qt3zAfmr)**
   （链接里已经带了邀请码 `Qt3zAfmr`，直接点开就行，不用手动填）
2. **注册并登录**：填手机号 → 收验证码 → 设置密码。（如果你已经有账号，直接跳第 3 小步）
3. **找到「API 密钥」页面**：登录后进控制台，左侧菜单里点 **「API 密钥」**。
   找不到就用这个直达地址：<https://cloud.siliconflow.cn/account/ak>
4. **点「新建 API 密钥」**：弹出的名字随便填（比如 `dsh`），点确定。
5. **复制那串 Key**：列表里会出现一行 `sk-` 开头的长字符串，点旁边的**复制**按钮。
   ⚠️ 这串东西**只完整显示这一次**，如果关掉页面又要重新建一把，所以复制完先别乱关。
6. **充 1 块钱当保证金**：头像 → 费用中心 / 充值，充 **1 元**即可。
   模型本身是免费的，但平台要求账户余额 **不能小于 0**，余额见底就会报「余额不足」。

> 💡 用的是免费的 Kolors 模型，出图不花钱。那把 `sk-` 开头的 Key 就是你的，别发给别人。

### 第 2 步 · 安装插件

**方式 A · 命令行**（最快）

```bash
dsh plugin --profile desktop add dsh-api-free-image
```

> 这条命令里的 `dsh-api-free-image` 是插件的包名，相当于在一家叫 npm 的「插件商店」里点了一下安装。**你不用懂 npm**，把整行复制进终端回车就行。

**方式 B · 图形界面**（不想碰命令行就用这个）

DSH → 左下角 **设置** → **插件** → **添加** → 包名填 `dsh-api-free-image` → 确定。

**方式 C · 别人发你一个 `.tgz` 文件**

DSH → 设置 → 插件 → 添加 → 直接选中那个 `dsh-api-free-image-1.1.0.tgz` 文件。

> ❗ 三种方式**只装一种**就够了。不要既有安装包、又同时链接了本地文件夹，那样 DSH 会启动崩溃。

### 第 3 步 · 填入 Key，开始画图

1. 打开 **设置 → 插件 → API免费生图**
2. 把刚才复制的 `sk-` 开头的 Key 粘进输入框 → 点 **保存**（输入框是密码样式，看不清是正常的）
3. 回到对话，说人话就行：

   > 画一只戴墨镜的柴犬，扁平插画风
   >
   > 来张 16:9 的赛博朋克城市夜景

## 图片存在哪里？

- **默认位置**：系统的「图片」文件夹（Windows 是 `C:\Users\你的用户名\Pictures`），**按日期分文件夹**存放。
- **想换位置**：设置卡片里点 **「更改保存位置」**，选一个新文件夹即可；点 **「恢复默认」** 可以改回来。

---

## 说明太长，想收起来？

设置卡片右上角（「✅ 已配置」左边）有个 **「收起说明」** 按钮，点一下这段说明整块收起；
点 **「显示说明」** 再展开。选择会被记住——下次进插件页还是你上次的样子。

## 常见问题

**提示「本分钟已经出过 2 张」？**
免费模型有限速，每分钟最多 2 张、每天最多 400 张。等一分钟再画就行。

**提示「余额不足」（402）？**
去硅基流动后台充 1 元。免费模型也要求账户余额 ≥ 0。

**提示「API Key 无效」（401）？**
Key 复制错了、漏了字符或被删除了，回第 1 步重新建一个。

**卡片显示「未配置」，但我明明填过 Key？**
Key 只存在你这台电脑上。重装系统、换电脑后需要重新填一次。

**需要先装 Node.js 吗？**
不需要。DSH 自带运行环境，插件是零依赖的。

## 想自己改代码？（不折腾可以跳过）

上面三步已经够用了，这一节是给「想动手改」的人看的。

```bash
git clone https://github.com/APFSDS-Dog/dsh-api-free-image.git
dsh plugin --profile desktop add "D:\Projects\dsh-api-free-image"
```

第一行是**把源码下载到本地**（`git` 就是管理代码版本的工具，这里只当下载器用），第二行是**把这个本地文件夹装进 DSH**。
改完代码要重新构建（`pnpm build`）再重启 DSH 才生效——完整的开发、打包、发布到 npm 的流程，都写在 [docs/交接单.md](docs/交接单.md) 里，这里不展开。
